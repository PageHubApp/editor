# Pattern library

`patternData.ts` is the SVG pattern library of Pattern Monster (https://pattern.monster,
https://github.com/catchspider2002/svelte-svg-patterns), the same library other editors ship.
Pattern Monster is MIT licensed; `LICENSE.md` beside this file is its licence text and must travel
with the data.

`patternData.ts` and `patternSlugs.ts` are generated by `packages/engine/scripts/gen-patterns.mjs`
from a JSON export of that library. Do not hand-edit them.
